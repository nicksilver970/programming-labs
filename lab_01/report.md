## 2. Краткие теоретические сведения
Язык Python является интерпретируемым. При первом запуске код транслируется в промежуточный байт-код и выполняется виртуальной машиной (CPython). 

- **Переменные** представляют собой ссылки (имена), связанные с объектами в динамической памяти.
- **Отступы** (ровно 4 пробела) обязательны и служат для группировки блоков кода.
- **Форматированные строковые литералы (f-строки)** позволяют удобно вставлять выражения в строки. Например, выражение `f'{pi:.3f}'` форматирует вещественное число с точностью до трех знаков после запятой.

## 3. Задание (Вариант 14)
Написать скрипт, вычисляющий силу натяжения троса при подъеме по формуле: `T = m * (g + a)`.
Исходные параметры: 
- `m = 1200.0` кг (масса)
- `g = 9.81` м/с² (ускорение свободного падения)
- `a = 1.5` м/с² (ускорение подъема)

*Требование:* Все переменные динамически привязаны к значениям. Вывод результата строго с помощью f-строк с округлением вещественной части до 4 знаков после запятой.

## 4. Листинг программы (Код)
```python
# Вариант 14: Вычисление силы натяжения троса
# Исходные данные согласно заданию
m = 1200.0
g = 9.81
a = 1.5

# Вычисление силы натяжения
T = m * (g + a)

# Вывод результатов с использованием f-строк и округлением до 4 знаков
print(f"Масса груза m: {m} кг")
print(f"Ускорение свободного падения g: {g} м/с^2")
print(f"Ускорение подъема a: {a} м/с^2")
print(f"Сила натяжения троса T: {T:.4f} Н")
